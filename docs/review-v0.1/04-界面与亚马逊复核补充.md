## 界面交付
使用内置 imagegen 生成 7 张概念图：[逐页预览](ui-previews/index.html)。覆盖商品发现、详情及复核面板、AI 研究台、候选池、任务中心、连接设置和控件状态。生成提示词见 [prompts.json](ui-previews/prompts.json)（后五张完整提示词）；前两张遵循相同低饱和 Carbon/Linear 方向，分别表现商品列表与商品详情。

视觉基线：炭灰导航、浅灰画布、白色面板、灰蓝主操作、细边框、4–6px 小圆角、紧凑表格。状态同时用文字和图标表示。正式实现统一图标、间距、字号和 token；生成图片不是组件代码，也不代表所有文案已定稿。

图片中的内容校正要求：
- 2024 等日期和候选池里的 Amazon 图标是生成示例，不能作为当前数据来源；实际初始平台为已取得的 Temu/SHEIN/TikTok/AliExpress 数据。
- 候选池出现的社交讨论、报告附件和研究判断均是布局占位，尚未取得这些证据。实际无来源时显示待补充。
- 四组极鲸云凭据是账号凭据组，不是“市场/关键词/广告”等不同权限套餐；设置页需改为组编号、连接状态、积分与预算，不承诺广告/流量能力。
- 极鲸云数据调用按积分管理；AI 按金额管理。研究台图中的数据预算美元符号应改为积分，并展示费用口径。
- 任务页标签数量按实际筛选结果计算；例图的数量不作为统计口径。
- 控件图的时区、预算、日期是状态演示；实际执行时间和上限仍待设置。
- 数据状态不得用进度条虚构覆盖比例；有可计算的分母时才能显示百分比。
- 不提供“任意竞品真实销量已获验证”的显示，不把搜索未命中称为不存在。
- 主管未确认前，候选阶段名和卡片字段均可调整；界面图不新增自动上架等范围。

## 亚马逊：现在的真实状态
已列入需求 F13、AC12 和来源适配架构，**尚未编写应用 SP-API 适配器，尚未配置或调用用户 SP-API，尚未进行真实复核**。现有 Python 探测仅针对极鲸云。

亚马逊复核的目的，是将发现的候选商品与美国站 Amazon 可比商品建立有证据的对应关系，供人工与 AI 判断价格区间、规格可比性和竞争环境。自动匹配只产生候选关系；不同规格、组合、材质不能直接视为同款。

用户已有 SP-API，实施顺序按本轮要求补充为：
1. 基础功能阶段同时建立 Amazon 配置入口、服务端密钥绑定、适配器契约、美国站配置、连接测试入口、未配置状态与权限错误显示。用户确认工程后实施；现在尚未实现。
2. 用户完成凭据配置后，先测试鉴权与真实账号可调能力，保留脱敏响应及字段覆盖说明。
3. 完成目录搜索/ASIN 明确选择 → 获取目录与可用报价 → 标准化快照 → 显示跨平台对照。
4. 加入匹配证据、人工确认、缺失项、时间戳、限流/退避和任务恢复，再将证据接入 AI 研究。
5. 验收可追溯结果后，才把对应状态标为“已复核”。已连接、查询成功和复核完成是不同状态。

推荐数据分工依据官方接口：
- [Catalog Items / getCatalogItem](https://developer-docs.amazon/sp-api/reference/getcatalogitem)：可请求目录摘要、标识、图片、属性、分类、尺寸、关系与销售排名等数据集；账号、商品和站点下的实际返回需验证。排名不是销量。
- [Product Pricing API](https://developer-docs.amazon/sp-api/docs/product-pricing-api)：获取商品价格与报价信息，按实际授权与返回字段做比较。
- 不预设任意竞品真实销量、评论全文、现成完整历史或 Haul 覆盖；缺少字段不写零。历史趋势只能使用已取得且来源明确的历史，或从接入后逐次留存快照。

初始状态链：未配置 → 连接测试 → 待匹配 → 待确认匹配 → 待复核 → 已复核/部分数据/查询失败。无匹配结果保留原因和检索条件；不自动判定 Amazon 无竞争。

## 验收补充
- 未配置：没有真实 Amazon 指标，提供配置入口；页面其余功能可用。
- 已配置：可验证鉴权、授权/站点、明确返回字段，且密钥不进前端、日志或模型输入。
- 商品匹配：保留源商品、候选 ASIN、匹配方法、规格差异和人工确认状态。
- 已复核：证据含接口、请求时间、供应商字段及失败/缺失标记；AI 推断与事实分别显示。
- 超时和限流不会写出“0 竞品”或“0 销量”；同一任务可以安全恢复。
