Seller Flex 批量库存助手 v0.7.3 — Pack 订单分拣、ERP 连接与库存任务

ERP 配对、Pack 分拣、自动补库、模拟任务、两行试跑及回传说明见 README.md。
Pack 功能：在 Pack 选择订单并打开 Order List，点击「同步到 ERP 并分拣」。插件只上传原生完整订单 XLSX；ERP 通过 Amazon SP API 获取标签，按固定「上欧代、下 SKU」版式合成并仅在 ERP 缓存。在 ERP 订单分拣页下载分拣表、标签或完整 ZIP。标签未就绪时后台自动重试；旧 ERP 必须升级，不回退到 Seller Flex 标签下载。插件不采集、上传或缓存 PDF，升级后清除历史 PDF 队列。相同 Transfer Id + SKU + FNSKU、数量相同自动跳过；数量变化待核对。不执行 Pack 或 Ship。
若导出超时、订单弹窗发生变化或同时手动下载其他文件，按提示刷新 Pack 后打开相同列表继续。网络中断后的已保存文件会自动重传；不要卸载插件，以免丢失本机尚未确认的文件。
ERP 启用自动补库后，从下一次新开始的巡检生成任务。A1C5 Receive 页面每批最多 2,900 行，补库差额按实时 API 库存计算。已出单商品及 A/B 组新品补到 5 件，C 组、集美组和未归组新品补到 2 件。
以下保留原版手动上传说明。手动点击提交会真实修改库存。

安装
1. 将 ZIP 解压到本地。
2. 在 Edge 打开 edge://extensions，开启「开发人员模式」。
3. 点击「加载解压缩的扩展」，选中含 manifest.json 的 sellerflex-inventory 文件夹。
4. 升级时在原目录更新后重新加载扩展，保留扩展 ID；不要卸载以免清除本地回执。
5. 同一浏览器配置文件打开 https://htcerp.app/settings?tab=inventory 并以管理员登录。点扩展图标，填写设备名称，点击「一键连接当前 ERP」。检测不会自动连接。
6. 连接仅登记本机，执行设备选择和交接在 ERP 库存页操作。配对码入口保留在备用折叠区。
7. 若 ERP 旧页面未加载连接脚本，请先保存表单，再手动刷新或打开新页；扩展不会自动刷新页面。
8. 打开 Seller Flex。升级后请在保存当前操作后手动刷新页面。保留 English (US) 界面语言。
9. 交接保存旧设备完整执行记录，已发放 CSV 的任务只核对不重复上传。旧设备撤销后的恢复也保留旧身份及回执；归档满 10 份会停止，请管理员核对备份。
10. 自动补库需保持 A1C5 Receive 页面打开；批次回执持久化后约五秒继续，空闲时一分钟检查。UNKNOWN 批次不会重复上传；其他 SKU 批次可继续。手动队列和用户已选择的文件会阻止自动上传。
11. 安装由用户在扩展管理页完成；本版本不会自动安装生产扩展。

使用
• Inventory → Receive。用 CSV 批量加库存，超过 3,000 条时自动拆分，每份最多 3,000 条并保留表头。
• Inventory → Adjustments。用 XLSX 批量下架，调整类型为 REMOVE。
• 在页面顶部的助手中选择或拖入多份文件。先看校验结果和当前仓库，再点一次「提交」。
• 助手逐份提交并查询 Amazon 状态。Completed 同时显示错误时，到原状态表查看错误明细。
• 文件名会追加 --sf- 标记，方便在原状态表里找到对应记录。超限 CSV 按拆分顺序逐份提交。
• 如遇状态不明、Amazon 弹窗或仓库切换，查看当前文件在 Amazon 的状态后再继续。提交过的同一文件会在同入口、同仓库去重。处理有错误时，应按 Amazon 错误明细整理需要重传的行。
• 下架的 XLSX 单份最多 3,000 条记录。请在 Excel 中删除无用空行、补齐数量，必要时拆成多份。CSV 建议用 UTF-8 编码。
• 文件在当前网页会话中读取，刷新页面后需要重新选择待提交文件。提交记录保存在扩展的本地存储。
