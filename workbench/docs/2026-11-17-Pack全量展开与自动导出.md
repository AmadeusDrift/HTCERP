# Pack 全量展开与自动导出 v0.7.1

## 用户确认的最终规则

- 当前日期、Shipout Time、Ready to pack / Packed 页签作为范围，不自动切换条件。
- 持续点击可用的 Load More，必须等按钮消失才判定分页结束。即使达到页签显示总数，或中间一轮没有新增行，也继续加载。不能把数量达标或超时当作完成。
- 分页结束后核对总数、全选、核对原生 Order List 全部明细，再自动导出完整 XLSX 至 ERP 分拣。
- 原有 Transfer Id + SKU + FNSKU 去重、数量变化待核对规则继续使用。新增行的 API 标签、主图缓存和带图备货单沿用 ERP 现有流程。
- 不执行 Pack / Ship；自动补库继续暂停。

## 实现与保护

新增 `extensions/sellerflex-inventory/pack-all.js`，由 manifest 在 `pack-content.js` 之前加载。新按钮「展开全部并导出到 ERP」串联分页、选择、原生导出与现有持久上传队列；原「导出当前所选订单到 ERP」入口保留。

真实页面分页期间 Load More 暂时 disabled，恢复后继续点击，点击间隔至少一秒。连续两分钟无明细进展或总过程超过十分钟停止并报错，不导出部分列表。加载期间可取消；开始持久同步后禁用取消，避免把可能已上传的数据标为取消。

全程检查日期、时段、页签/总数、仓库和订单身份/数量。支持一个 transshipment 多 SKU 的 rowspan 表格与隐藏样式的原生 checkbox。加载数不足、重复行、不可选择、弹窗和页面不一致、Load More 重新出现等情况停止上传。12 MB 文件及 10,000 行限制保留。搜索非空时提示清空搜索或改用指定订单入口。
