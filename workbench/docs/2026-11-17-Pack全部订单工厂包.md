## 行为

- 新增「导出本次全部订单工厂包」。从当前批次归档的完整 Order List 读取全部订单，按当前 ERP 属性清单分组，生成 ZIP。
- 每个分组包括分拣表 XLSX、固定欧代标＋Amazon API SKU 条码 PDF、带商品主图的备货单 XLSX；另含原始订单与批次说明。
- 原按钮显示为「下载新增订单分拣包」，原导入台账、数量变化待核对和去重规则保持不变。
- 相同 Transfer Id + SKU + FNSKU 在同一来源中只计算一次；数量冲突、未入账项目或源文件校验失败会阻止整包生成。
- 复用 ERP 标签、主图和生成文件缓存；重复导出返回同一文件。属性清单版本或模板变化会生成新包。
- 包未完整生成时不返回成品 ZIP。店铺范围、登录权限、operator 生成权限和下载归属校验已覆盖。
- 输出累计大小超过 24 MiB 时提示分时段导出；此值是生成文件大小限制，不代表已证明峰值内存上限。
