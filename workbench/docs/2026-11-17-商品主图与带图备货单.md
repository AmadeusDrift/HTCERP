## 流程

Pack 原始订单导入、去重、分拣后，自动准备 API 标签和带图备货单；两者齐全才显示 READY。已有批次可以通过“生成／重试备货单和标签”补齐图片；此操作不重写订单去重账本。完整 ZIP 包含原始订单、原分拣表、带图备货单和 API 标签。

主图按当前店铺 + 美国站 + 完整 SKU 查询 Listing，取得该商品 ASIN，再选择 Catalog 的最大 MAIN 图片。保留现有其他模块的小图行为。下载只允许 Amazon 图片 HTTPS 域名、不跟随重定向、不携带 LWA 凭据到图片服务器；检查文件长度和 JPEG/PNG 尺寸。

图片与生成 XLSX 保存于私有 R2；D1 的 product_image_cache 通过可续租、带持有者校验的锁控制并发，下载校验 SHA-256，缺失/损坏对象重新生成。同一批次生成后的 XLSX 保持固定，重复下载返回相同字节。图片从 ERP 读取，浏览器只接收最终用户下载文件。

备货单按工厂样例主要列组织：E 图片、F SKU、G FNSKU、H 数量；标准嵌入图片，不依赖 WPS DISPIMG 或联网链接。第 4 行表头，第 5 行起明细，合计覆盖全部明细；保留原始订单工作表。规格、尺寸、单价、包装来自当前 ERP 属性清单。缺图时指出 SKU，不缓存或提供伪装完整的工厂备货单，可重试；其他分组继续生成。单张图片最多 8 MiB；单组累计图片超过 24 MiB 或生成文件超过 32 MiB，提示拆分批次。
